# AI Frontier Research Methodology

## Research Pipeline
1. **Discover** - Search arXiv, PapersWithCode, and AI blogs for latest papers
2. **Filter** - Prioritize by: novelty, citation potential, practical impact, relevance to user's interests
3. **Read** - Extract abstract, method, key results, limitations
4. **Explain** - Translate technical concepts into intuitive explanations
5. **Report** - Write structured reports in Chinese with the user's required format

## Key Sources
- arXiv (cs.AI, cs.LG, cs.CL, cs.CV)
- PapersWithCode
- GitHub trending in AI/ML
- Major conference proceedings (NeurIPS, ICML, ICLR, CVPR, ACL)

## Report Format Required Fields
Each paper/technology in the report MUST include:
- **Name**: Full paper title or technology name
- **Domain**: Which subfield of AI (e.g., NLP, Computer Vision, Reinforcement Learning, AI Agent, LLM, etc.)
- **Summary**: Main content and contributions
- **Key Points**: 3-5 core technical highlights
- **Plain Explanation**: Explain in simple terms accessible to a general technical audience
- **Glossary**: Define any specialized terminology used
- **Impact Score**: 1-10 rating (10 = revolutionary, 1 = incremental)
